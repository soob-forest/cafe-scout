# 한국 카페 음료 1잔 수익성 조사

> 조사 기준일: 2026-08-24
> 범위: 대한민국 커피 전문점, 소비자가 표시가격과 매장 영업손익
> 결론의 기준 자료: 2025 외식업체 경영실태 조사(2024년 실적)

## 요약

카페 음료는 **재료비만 보면 많이 남지만, 매장 전체 비용까지 배분하면 적게 남는다.**

- 4,500원 아메리카노의 재료·포장 원가는 약 **730–1,110원**으로 추정된다. 이 단계의 제품 매출총이익률은 약 **75–84%**다.
- 결제수수료와 제조에 직접 투입된 시간만 더 빼도 약 **62–78%**가 남지만, 이는 임차료·대기시간·청소·관리·감가상각·세금·대표자 노동비를 차감하기 전의 공헌이익이다.
- 농림축산식품부·한국농촌경제연구원의 최근 실적 조사에서 커피 전문점의 평균 영업이익률은 **약 8.9%**였다. 대표자와 가족의 노동비도 영업비용에 포함한 결과다.
- 따라서 4,500원이 회계상 매출이라면 평균적으로 약 **400원**, 4,500원 표시가격에 부가가치세 10%가 포함된 일반과세자라면 공급가액 4,091원 기준 약 **360원**의 영업이익이 대응한다.
- 실무 결론은 **“한 잔당 평균 영업이익 약 350–400원, 추가 한 잔의 한계 공헌이익 약 2,800–3,500원”**이다. 두 수치는 서로 다른 질문에 대한 답이다.

## Problem 1-Pager

### 배경

Cafe Scout의 `mvp-v1`은 관찰한 좌석, 점유율, 체류시간과 객단가로 매출을 추정한다. 현재 제품 명세는 원가 연동과 손익분기점 계산을 MVP 범위에서 제외한다.

### 문제

메뉴 가격에서 원두값만 뺀 값을 “수익”으로 부르면 70–80%가 남는 것처럼 보이지만, 실제 점포의 임차료·인건비·대표자 노동비를 반영한 영업이익률은 훨씬 낮다. 제품 원가율과 점포 수익률을 같은 숫자로 취급하면 창업 판단이 왜곡된다.

### 목표

1. 음료 1잔의 제품 매출총이익과 점포 영업이익을 구분한다.
2. 공공 통계로 실제 점포의 기준 수익률을 산출한다.
3. 대표 음료 1잔을 상향식·하향식으로 계산하고 결과 범위를 제시한다.
4. 향후 Cafe Scout 수익성 모델이 사용해야 할 입력과 출력의 경계를 제안한다.

### 비목표

- 특정 매장의 세후 순이익 보장
- 프랜차이즈별 로열티·필수품목 차액가맹금 비교
- 권리금, 대출 원금, 창업 투자금 회수기간 계산
- 현재 `mvp-v1` 매출 추정식 변경

### 제약

- 최신 공공 손익자료는 2026년 현재에도 2024년 실적을 사용한다.
- 공공 통계는 메뉴별 손익이 아니라 매장 전체 손익이다.
- 같은 4,500원이라도 과세유형, 판매채널, 임차료와 시간당 판매량에 따라 잔당 이익이 달라진다.

## 먼저 구분할 세 가지 이익

| 지표            | 계산                                         | 답하는 질문                                      |
| --------------- | -------------------------------------------- | ------------------------------------------------ |
| 제품 매출총이익 | 판매가 - 재료·포장                           | 레시피 자체가 얼마나 남는가?                     |
| 공헌이익        | 판매가 - 주문과 함께 증가하는 비용           | 한 잔을 더 팔면 고정비 회수에 얼마가 보태지는가? |
| 영업이익        | 매출 - 재료·인건비·임차료·세금·기타 영업비용 | 매장 운영 전체가 실제로 얼마나 남는가?           |

여기서 “수익률”의 분모는 매출이다. 창업 투자금 대비 수익률(ROI)과는 다르다.

## 조사 방법과 대안 비교

### 대안 A — 레시피별 상향식 원가 계산

- 장점: 원두 투입량, 우유, 시럽, 컵을 메뉴별로 바꾸어 가격 결정을 할 수 있다.
- 단점: 임차료, 비판매 시간의 인건비, 감가상각 등 점포 고정비가 빠지기 쉽다.
- 위험: 75–84%의 제품 매출총이익률을 순이익률로 오인할 수 있다.

### 대안 B — 실제 점포 손익의 매출비례 배분

- 장점: 대표자 노동비까지 포함한 실제 운영 결과를 반영한다.
- 단점: 아메리카노, 라떼, 디저트의 원가 차이가 평균 속에 섞인다.
- 위험: 고정비가 이미 지출된 상태에서 한 잔을 추가 판매할 때의 경제성을 과소평가한다.

### 선택

두 방식을 함께 사용한다. 가격 결정에는 대안 A의 공헌이익을, 창업·점포 평가에는 대안 B의 영업이익을 사용한다. 하나의 “잔당 이익”으로 합치지 않는다.

## 실제 커피 전문점의 손익 기준선

[2025 외식업체 경영실태 조사 통계보고서](https://ipsi.u1.ac.kr/u1job/community/notice.do?articleNo=76274&attachNo=51231&mode=download)는 2024년 실적을 조사했다. 커피 전문점 표본은 261개다.

| 항목               |           연평균 | 매출 대비 | 매출 1,000원당 |
| ------------------ | ---------------: | --------: | -------------: |
| 매출               |    196,945,000원 |    100.0% |        1,000원 |
| 식재료비           |     76,924,000원 |     39.1% |          391원 |
| 고용인 인건비      |     32,382,000원 |     16.4% |          164원 |
| 대표자 인건비      |     25,331,000원 |     12.9% |          129원 |
| 가족 종사자 인건비 |      5,207,000원 |      2.6% |           26원 |
| 임차료             |     16,512,000원 |      8.4% |           84원 |
| 세금과 공과        |     11,754,000원 |      6.0% |           60원 |
| 기타비용           |     11,346,000원 |      5.8% |           58원 |
| **영업이익**       | **17,488,000원** |  **8.9%** |       **89원** |

연평균 영업이익률은 `17,488,000 ÷ 196,945,000 = 8.88%`다. 같은 조사의 커피 대표메뉴 평균 가격은 4,112원이었다.

[농림축산식품부의 2025 조사 보고서](https://www.mafra.go.kr/bbs/home/798/595246/download.do)도 비알코올 음료점업의 평균 연매출을 약 1억 9천만 원으로 제시해 규모가 일치한다.

국세청의 [2025년 귀속 기준경비율·단순경비율](https://in.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=135773&nttSn=1350751)에서 커피 전문점(업종코드 `552303`)의 단순경비율은 87.5%다. 역산한 12.5%는 소규모 추계신고용 소득률이지 실제 평균 이익률은 아니지만, 공공 조사치 8.9%가 비현실적으로 낮은 숫자는 아니라는 보조 점검으로만 사용할 수 있다.

## 아메리카노 1잔 상향식 계산

기준 판매가는 4,500원, 더블샷 원두는 18g으로 둔다. 현재 업계 원가 예시는 18g 원두 540원·포장 140원을 사용하거나, 원두 45원/g·컵류 200원을 사용한다. 두 사례를 범위의 양 끝으로 사용했다.

| 직접 항목            |   낮은 원가 |   높은 원가 | 산식·가정               |
| -------------------- | ----------: | ----------: | ----------------------- |
| 원두                 |       540원 |       810원 | 18g × 30–45원/g         |
| 컵·뚜껑·홀더         |       140원 |       200원 | 테이크아웃 1세트        |
| 물·전력·추출 로스    |        50원 |       100원 | 점포별 교체 가능한 가정 |
| **재료·소모품 합계** |   **730원** | **1,110원** | 판매가의 16.2–24.7%     |
| **제품 매출총이익**  | **3,770원** | **3,390원** | **75.3–83.8%**          |

근거가 된 원가 예시는 [KitchenCost의 2026 카페 원가 가이드](https://kitchencost.app/ko/blog/cafe-menu-cost-guide/)와 [CafeInfo 원가 관리 가이드](https://cafeinfo.net/05_cost_management)다. 둘 다 공공 통계가 아닌 실무 예시이므로 매입명세서로 교체해야 한다.

추가 변동비를 반영하면 다음과 같다.

- 2026년 영세·중소가맹점 신용카드 우대수수료율 0.4–1.45%를 적용하면 잔당 약 18–65원이다. 실제 현금·체크카드·PG 구성에 따라 달라진다.
- 2026년 최저임금 10,320원으로 1.5–3분의 전용 제조시간을 계산하면 258–516원이다. 주휴, 보험과 퇴직급여는 별도이며, 바리스타의 대기·청소 시간도 포함하지 않는다.
- 이를 단순 차감한 주문 단위 잔여액은 약 2,809–3,494원, 판매가의 62.4–77.6%다. **이 값도 영업이익이 아니다.**

카드수수료는 [금융위원회 2026년 하반기 자료](https://www.fsc.go.kr/no010101/87498), 최저임금은 [최저임금위원회 고시](https://www.minimumwage.go.kr/minWage/policy/decisionMain.do)를 사용했다.

## 같은 4,500원에서 실제로 남는 금액

공공 조사 평균을 매출비례로 배분하면 회계상 매출 4,500원은 다음처럼 나뉜다.

| 배분 항목                 | 잔당 금액 |
| ------------------------- | --------: |
| 식재료비                  |   1,758원 |
| 고용인·대표자·가족 노동비 |   1,438원 |
| 임차료                    |     377원 |
| 세금과 공과               |     269원 |
| 기타비용                  |     259원 |
| **영업이익**              | **400원** |

이 표의 식재료비가 레시피 계산보다 높은 이유는 라떼·디저트 등 전체 메뉴 구성, 폐기와 매입 로스가 평균에 섞였기 때문이다. 특정 아메리카노의 정확한 원가표로 사용하면 안 된다.

카페 표시가격에는 통상 부가가치세가 포함된다. 일반과세자의 4,500원 표시가격은 공급가액 약 4,091원과 부가가치세 약 409원으로 나뉜다. 국세청도 공급가액과 세액을 따로 표시하지 않은 음식용역 대가에는 부가가치세 10%가 포함된 것으로 본다. 자세한 원칙은 [국세청 질의회신](https://taxlaw.nts.go.kr/qt/USEQTA002P.do?ntstDcmId=010000000000135292)을 따른다.

따라서 공급가액에 평균 영업이익률을 적용한 값은 `4,091 × 8.88% ≈ 363원`이다. 간이과세 여부와 매입세액 공제에 따라 실제 납부세액은 달라진다.

## 가격별 잔당 평균 영업이익 민감도

아래 표는 표시가격에 부가가치세가 포함된 일반과세자를 가정하고 `표시가격 ÷ 1.1 × 8.88%`를 계산한 것이다. 실제 메뉴별 원가 차이는 반영하지 않았다.

| 표시가격 | 공급가액 | 평균 영업이익 배분 |
| -------: | -------: | -----------------: |
|  1,700원 |  1,545원 |              137원 |
|  3,000원 |  2,727원 |              242원 |
|  4,112원 |  3,738원 |              332원 |
|  4,500원 |  4,091원 |              363원 |
|  5,500원 |  5,000원 |              444원 |
|  7,000원 |  6,364원 |              565원 |

저가 커피가 낮은 가격으로도 운영되는 핵심은 잔당 원두값보다 **판매량, 제조 동선, 점포 면적과 인력의 동시 활용**이다. 같은 임차료와 근무시간 안에서 판매량이 늘면 잔당 고정비가 급격히 낮아진다.

## 해석과 의사결정

1. **메뉴 가격 결정:** 제품 매출총이익률보다 공헌이익액을 본다. 저가 메뉴도 피크타임 처리량이 높으면 유효하다.
2. **점포 사업성 판단:** 공공 조사 평균 8.9%를 시작점으로 두되, 임차료·대표자 노동비·실제 판매량을 매장별로 교체한다.
3. **추가 판매 판단:** 고정비가 이미 발생한 시간대의 한 잔은 약 2,800–3,500원을 고정비 회수에 보탤 수 있다.
4. **폐점·창업 판단:** 잔당 3천 원이 남는다는 이유로 월 판매량을 곱하지 않는다. 평균적으로 최종 영업이익에 대응하는 금액은 4,500원 음료당 약 360–400원이다.
5. **대표자 노동:** 대표자가 직접 근무해 통장에 더 많은 현금이 남더라도, 노동비를 이익으로 계산하지 않는다. 공공 조사처럼 정상 인건비를 비용 처리해야 다른 투자와 비교할 수 있다.

## Cafe Scout에 대한 제안

현재 명세가 원가·손익분기점을 MVP에서 제외한 판단은 유지한다. 이 조사치를 `mvp-v1` 매출에 고정 8.9%로 곱해 “예상 이익”을 표시하는 것도 권하지 않는다. 매장별 임차료와 인력 구조의 영향이 너무 크기 때문이다.

향후 별도 모델을 만든다면 최소 입력은 다음과 같다.

- 메뉴별: 표시가격, 원두/우유/시럽, 포장, 결제채널, 예상 판매비중
- 매장별 월 비용: 고용인·대표자 노동비, 임차료, 공과금, 로열티, 감가상각
- 운영량: 월 주문수, 메뉴 믹스, 배달·테이크아웃 비중
- 세무: 일반/간이과세 구분과 가격의 부가세 포함 여부

출력도 `제품 매출총이익`, `공헌이익`, `배분 영업이익`, `손익분기 주문수`를 분리해야 한다. 모델 버전은 기존 매출 모델과 별개의 `profitability-v1`처럼 관리하는 편이 안전하다.

## 가정과 한계

- 조사 대상은 한국 카페이며, 2024년 평균 실적을 2026년 의사결정의 기준선으로 사용했다.
- 공식 조사에서 대표자·가족 인건비는 비용으로 처리했다. 본 보고서도 같은 경제적 관점을 따른다.
- 잔당 영업이익은 매장 전체 이익을 매출비례로 배분한 추정값이지 특정 메뉴의 회계 추적값이 아니다.
- 영업이익은 금융비용, 소득세와 대출 원금 상환 후의 세후 순이익이 아니다.
- 프랜차이즈 로열티, 배달 플랫폼 수수료와 차액가맹금은 매장별 계약을 확인해야 한다.
- 재료 가격 예시는 배송비·할인·사업자 매입조건에 따라 바뀌므로 실제 매입명세서로 갱신해야 한다.
