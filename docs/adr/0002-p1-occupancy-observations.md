# ADR-0002: P1 시간대별 추가 관찰과 `mvp-v1` 분리

- 상태: Accepted
- 결정일: 2026-08-18

## 배경

P0의 단일 방문 snapshot은 현장에서 빠르게 사업성을 기록하는 데 적합하지만, 같은 방문 중 여러 시각의 점유 변화를 표현하지 못한다. P1은 추가 관찰을 저장하고 시간대별 평균을 보여주되, 검증되지 않은 소수 관찰이 기존 매출 추정식을 암묵적으로 바꾸지 않게 해야 한다.

## 결정

P0 핵심 흐름과 로컬 보안·E2E 검증을 통과한 뒤 P1 추가 관찰을 활성화한다.

- 서울 시각 기준으로 `00~06`, `06~11`, `11~14`, `14~17`, `17~20`, `20~24` 구간을 사용한다.
- 고객 수가 입력되면 해당 방문 snapshot의 좌석 수로 점유율을 계산하고 100%로 제한한다.
- 구간 평균은 점유율이 있는 관찰만 산술 평균한 뒤 정수로 반올림한다. 빈 구간은 표시하지 않는다.
- P1 관찰은 참고 시각화이며 기존 매출 추정 입력에는 합산하지 않는다.
- 따라서 저장된 매출 모델 버전은 계속 `mvp-v1`을 사용한다.
- 향후 P1 관찰을 매출에 반영하려면 별도 검증 데이터, 계산식, migration, ADR과 새 모델 버전(예: `mvp-v2`)이 필요하다.

## 결과

여러 시각의 관찰 추이를 볼 수 있으면서 기존 snapshot의 재현성과 P0 계산값은 유지된다. 시간대 경계, 자정 전후, 다중 관찰 평균, 빈 구간과 사용자 격리는 단위 및 통합 테스트 대상으로 둔다.
